# fairseq2

Sequence modeling toolkit for research and production. Core infrastructure for FAIR translation and language models.

## Overview

**Goal**: Maintain and extend fairseq2 for next-gen models
**Stack**: PyTorch, distributed training, C++ extensions
**Team**: Infrastructure
**Version**: v0.7+
